### Experiment name and goal

- **Name:** Learning-sized Qwen2.5-VL component implementation and validation.
- **Goal:** Build inspectable vision, vision-language merger, and causal
  language-model components from scratch, with explicit tensor movements and
  deterministic checks. This is an educational model, not a reproduction of
  released Qwen2.5-VL scale or benchmark performance.

### Model, dataset, and configuration

#### Vision model

- Default study input: RGB `700x1260`; patch size `14`, producing a `50x90`
  grid and 4,500 patch tokens.
- Hidden size `64`, 4 attention heads, head dimension `16`, intermediate size
  `192`, depth `2`, RMSNorm epsilon `1e-6`, and RoPE theta `10,000`.
- The CIFAR-10 training path overrides the image size to `56x56`, producing a
  `4x4` grid (16 patch tokens), and adds a 10-class head.

#### Vision-language merger

- Vision width `64`, language width `96`, spatial merge size `2`.
- Each 2x2 group combines four vision tokens, so the grouped width is `256`
  before projection to width `96`.

#### Language model exercises

- Vocabulary size `128`, hidden size `96`, 4 attention heads, head dimension
  `24`, intermediate size `256`, 2 layers, maximum sequence length `128`,
  RMSNorm epsilon `1e-6`, and RoPE theta `1,000,000`.
- `num_key_value_heads=2` is retained for a later grouped-query attention
  lesson; the current completed attention exercise uses standard four-head MHA.
- The language SwiGLU MLP exercise remains intentionally incomplete.

#### Dataset and training defaults

- Dataset reference: CIFAR-10 loaded through `torchvision.datasets.CIFAR10`.
  Exact dataset release/version metadata is unknown.
- Deterministic split in code: 45,000 training, 5,000 validation, and the
  standard 10,000-example test split.
- Default training configuration: image size `56`, batch size `128`, 20
  epochs, AdamW learning rate `3e-4`, weight decay `0.05`, cosine schedule,
  4 workers, and seed `7`.
- Training augmentation: random crop with padding 4, random horizontal flip,
  resize, tensor conversion, and CIFAR-10 normalization. Evaluation uses
  resize, tensor conversion, and the same normalization.
- No local dataset, checkpoint, history, or training-output artifact was found.
  Training metrics are therefore **unknown**.
