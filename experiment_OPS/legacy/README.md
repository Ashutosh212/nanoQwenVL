# Preserved historical material

[Migration manifest](migration-manifest.json) maps each original path to its new path, source Git revision, byte count and SHA-256. Dated daily notes moved into Sunday-based weekly folders. Other notes stay under `legacy/experiments/` because their dates or role are uncertain or they are obsolete setup/test documents.

Original bytes and provenance are preserved. Historical paths and commands inside old notes describe the old configuration; do not use them as current instructions. There were no Markdown links in the source files needing relocation. Use the [current notebook guide](../README.md) and the manifest to resolve historical paths. Pre-migration notes/configs also have a local persistent backup at `/sfs/markdown-sync/backups/20261008T083148Z/` (no tokens copied).
